# Vokselnisan1

## Kuzgun Tepesi

Tarayıcıda oynanan voksel 3D keskin nişancı oyunu.

**Oyna:** https://akbgroup.github.io/Vokselnisan1/

| Tuş | İşlev |
| --- | --- |
| Fare | Nişan al |
| Sol tık | Ateş et |
| Sağ tık (basılı) | Dürbün |
| Tekerlek | Dürbün büyütmesi 4× – 12× |
| Shift (basılı) | Nefesini tut |
| R | Şarjör değiştir |
| Esc | Duraklat |

Kafadan vuruş 250, gövde 100 puan; her metre +1.
